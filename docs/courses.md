# Online courses and sessions

Edit `_data/courses.json` to change the three course descriptions in English, Russian, Ukrainian, and Portuguese.

Each course has an independent `url` field. Set it to the full course information or purchase URL. An empty value uses the Instagram link from `_data/contact.yml`. Prices and detailed terms are kept on the destination page, not on this site.

Change Instagram and Telegram links in `_data/contact.yml`. The individual training copy and consultation block are in `_data/locales.json`, under `training` and `consultation` for each language.

Language-neutral `/courses/` and `/online-training/` links use the existing browser-language detection. Language-specific pages are stable and support the navigation language selector.
